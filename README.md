🌿 Digital Wellbeing Analyzer
📌 About the Project

Digital Wellbeing Analyzer is a Python-based desktop application that automatically tracks the time spent on different applications on a Windows computer.

It helps users understand their screen time, monitor productivity, and maintain a healthy balance between study and entertainment.

✨ Features
Automatically tracks active applications.
Detects user idle time.
Categorizes applications into Study, Social Media, Entertainment, Browser, and Other.
Displays total application usage time.
Shows usage statistics through graphs.
Provides an interactive dashboard.
Exports usage reports in CSV format.
🛠️ Technologies Used
Python
Tkinter
NumPy
Pandas
Matplotlib
Windows API (ctypes)
💻 Requirements
Windows 10/11
Python 3.9 or above
